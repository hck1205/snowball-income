# Dividend Platform Roadmap (v2)

> 2026-07-27 사용자 확정. v1(docs/ROADMAP.md)을 대체하는 상위 방향 문서.
> 핵심 전환: "계산기"가 아니라 **배당 투자자의 성장 과정을 기록하고 공유하는 플랫폼**.
>
> ```
> Simulator → Portfolio → Goal Progress → Community → SEO + SNS
> ```

## 1. Portfolio (현재 상태)

**목적**: 사용자의 현재 포트폴리오를 관리한다.

**사용자 입력**: 티커 + 보유 수량 (예: SCHD 120주 / VIG 80주 / JEPQ 45주)

**자동 계산**: 현재 자산 가치 · 연배당 · 월배당 · 배당수익률 · 예상 세후 배당 · 이번 달 예상 배당 · 다음 배당 지급일

## 2. Simulator (미래)

**목적**: 앞으로 어떻게 투자하면 목표를 달성하는지 계산.

**사용자 입력**: 매월 투자금 (+ 배당 재투자 ON/OFF)

**결과**: 10년 후 월배당 / 총 자산 / 누적 배당

## 3. Goal Progress (핵심 기능)

**목적**: 현재 포트폴리오와 시뮬레이터를 연결하는 **허브** — "지금 나는 어디까지 왔는가".

**사용자 입력** (처음 한 번만): 목표 월배당 — 칩 `50만원 / 100만원 / 200만원 / 300만원` + 직접 입력

**자동 계산**: 현재 포트폴리오 → 현재 월배당(예: 82만원) → 달성률(27%) → **남은 금액(218만원)**

**시뮬레이터와 연결**: 버튼 **"언제 목표를 달성할까요?"** → 현재 포트폴리오 + 매월 투자금으로 기존 시뮬레이터 실행 → "2034년 8월 목표 달성". Goal은 현재 상태 + 미래 시뮬레이션을 잇는 허브다.

## 4. FIRE Dashboard

**목적**: 배당으로 생활비를 얼마나 해결했는지.

**사용자 입력**(선택): 은퇴 후 생활비 (예: 300만원)

**자동 계산**: 현재 월배당 → 생활비 커버율(27%). 항목별 커버 예시: 식비 100% · 관리비 100% · 통신비 100% · 보험료 71% · 생활비 27%

## 5. ETF Compare

**목적**: ETF 비교 + SEO 확보. `SCHD vs VIG` · `SCHD vs JEPI` · `SCHD vs DGRO`

비교 항목: CAGR · 총수익 · 배당률 · 운용보수 · 배당 성장률 · 지급월 · 최대 낙폭 · 섹터

## 6. ETF Detail

**목적**: 티커별 SEO 페이지 (`/etf/SCHD`). 배당률 · 배당 성장 · 운용보수 · 섹터 · 지급월 · 최근 배당 · 배당 히스토리 · 유사 ETF

## 7. Dividend Calendar

**목적**: 매달 방문하게 만드는 기능. "이번 달 예상 입금 $184" 자동 계산. 배당락일 · 지급일 · 예상 지급액 · 이번 달 총 배당 표시.

## 8. Community Integration

**목적**: 커뮤니티와 포트폴리오 연결. 게시글에 포트폴리오 첨부 → 자동 카드 생성(현재 월배당/목표/달성률). **"내 조건으로 계산"** 버튼 → 다른 사용자가 자기 월 투자금으로 바로 시뮬레이션.

## 9. Dividend Journey

**목적**: 성장 기록 자동 생성 (연도별 월배당 추이: 2026 12만 → 2027 32만 → 2028 51만 → 2029 82만). SNS 공유 가능.

## 10. Achievement (Gamification)

🥉 첫 배당 · 🥈 월배당 10만원 · 🥇 월배당 50만원 · 💎 월배당 100만원 · 🚀 목표 달성 50% · 🏆 FIRE 달성

## 데이터 구조 — 사용자 입력 최소화

| 기능 | 사용자 입력 | 나머지는 자동 계산 |
|------|-------------|---|
| Portfolio | 티커 + 보유수량 | 자산가치·연/월배당·수익률·세후·이번달·다음지급일 |
| Goal | 목표 월배당 (1회) | 달성률·남은 금액 |
| Simulator | 월 투자금 (+재투자) | 예상 달성일·10년 후 월배당·총자산·누적배당 |
| FIRE | 생활비 (선택) | 커버율 |

자동 계산 파이프라인: Portfolio → 현재 월배당 → Goal → 달성률 → Simulator → 예상 달성일 → FIRE → 커버율 → Community → 공유 카드

## 핵심 철학

사용자는 "계산"하러 방문하지 않는다. 자신의 **성장·진행률·목표·성과**를 확인하러 다시 방문한다.
서비스는 계산기가 아니라 **배당 투자 성장 플랫폼**이 되어야 한다.

## (부록) 2026-07-27 현재 구현과의 정렬 메모

- Goal Progress의 "현재 월배당"은 v2에서 **실보유 포트폴리오(티커+수량)** 기반이다. 보유수량 Portfolio 도메인이 생기기 전까지는 시뮬레이션 파생값(오늘 기준 롤링 12개월, 초기 폴백 1년차 평균)을 과도기 정본으로 쓰고, Portfolio 도메인 랜딩 시 실측 기반으로 교체한다.
- 목표 칩은 v2 확정값 `50/100/200/300만원`(+직접 입력)으로 통일한다 (구 100/300/500 결정 대체 — GA value_bucket 경계도 함께 갱신).
- 기존 배당 캘린더(/dividend/calendar)·티커 SEO 페이지(/ticker/*)는 v2의 §7·§6에 대응하는 기존 자산이다. `/etf/*` 경로 전환 여부는 미결정.
